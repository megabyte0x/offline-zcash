Prepare for offline

Split one mined note into equal notes so you can make several payments without a connection.

  1. Prepare while a gateway is reachable.
  2. Wait until the split shows mined (10 confirmations on testnet).
  3. Sync, then go offline. Never spend unmined change.
The split fee grows with the number of notes.
